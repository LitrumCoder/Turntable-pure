# Turntable

Виджет-проигрыватель пластинок для рабочего стола Windows. Показывает, что сейчас играет на компьютере — Spotify, Яндекс Музыка, YouTube в браузере, любой плеер, который отдаёт трек в системные медиа-контролы Windows (GSMTC), — с обложкой альбома на вращающейся пластинке.

Сам звук виджет не трогает: только читает метаданные и управляет плеером (пауза, следующий, предыдущий).

## Возможности

- Четыре скина: Pioneer (орех и алюминий), Studio (алюминиевая плата), Braun (минимализм), Dual (тик).
- 3D-вид для любого скина: сверху, в перспективе, под углом, строго спереди. Колесо мыши — наклон, Shift + колесо — поворот.
- Тонарм показывает прогресс трека, на паузе уходит на стойку.
- Анимация смены пластинки при переключении трека.
- Обложки в высоком качестве через iTunes Search API.
- Подсветка корпуса цветом обложки.
- Перетаскивание с мягким «примагничиванием» к правому нижнему углу, позиция запоминается.
- Скрывается во время полноэкранных игр и видео.
- Иконка в трее и меню по правому клику: скин, вид, автозапуск.

## Сборка

Нужны Rust, Node.js и Visual Studio Build Tools (C++).

```bash
npm install
npm run tauri dev
```

Готовый exe:

```bash
npm run tauri build
```

## Стек

Tauri 2, интерфейс на HTML/CSS/JS без фреймворков, системная часть на Rust (крейт `windows` для GSMTC и WinRT HttpClient).
